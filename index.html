📥 Import z brokera
XTB (.xlsx) – otevřené pozice, uzavřené obchody i dividendy.
Trading 212 (.csv) – z historie transakcí dopočítá pozice (FIFO), prodeje a dividendy. Export je po rocích, nahraj klidně všechny najednou.
Screenshot – rozpoznání funguje jen při spuštění uvnitř Claude.ai.
Opakovaný import data daného brokera nahradí, nic se nezdvojí.

⚙️ Nastavení

Automatické nastavení GitHubu

Jedním kliknutím založí repozitář, nahraje do něj aplikaci, vytvoří Gist s daty, uloží secrets, zapne GitHub Pages a stáhne ceny. Potřebuješ token s oprávněními repo, workflow, gist: vytvořit token na GitHubu. Novou verzi aplikace později nahraješ stejným tlačítkem.

Ruční nastavení

Token a ID Gistu se ukládají jen v tomhle prohlížeči. Na každém zařízení je zadej jednou.

Tickery na Yahoo Finance

Podle těchto symbolů stahuje GitHub Action ceny. Když u tickeru svítí „nenalezen“, oprav symbol (např. ASML.AS, VOD.L) a klikni na ☁️ Stáhnout ceny.

Data podle brokera
